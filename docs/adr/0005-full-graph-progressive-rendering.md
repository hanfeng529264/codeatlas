# ADR-0005：完整图采用 WebGL 与分级渲染

## Status

Accepted

## Context

完整空间图是产品最终事实视图。中大型仓库可能包含十万到百万节点和更多关系，一次绘制所有标签和边几何会造成不可读和性能问题，但默认隐藏或裁剪节点又违背完整图的产品原则。

## Decision

完整图使用 WebGL 渲染，并采用语义缩放、社区/层级聚合、视口分块和按级别展示标签与边。底层总量始终可见，聚合节点必须可展开。聚合只改变显示粒度，不删除底层事实。任何筛选、截断和聚焦都必须显式展示并可撤销。

## Consequences

### Positive

- 保留完整空间的真实性和用户自主切入能力。
- 大图仍能保持基本交互性能。
- 远景适合观察项目、模块、社区和异常连接。
- 近景可以恢复方法和具体关系细节。

### Negative

- 聚合算法、布局缓存和坐标稳定性实现复杂。
- 不同 GPU 和浏览器需要降级策略。
- 用户看到的远景节点不是一一对应的原始节点，需要清晰图例。

### Neutral

- 极大规模下首屏是全量图的多级摘要，而不是所有节点的独立标签。

## Alternatives Considered

- 默认只显示局部图：可读但不满足完整图定位。
- SVG/DOM 全量渲染：开发直观，但无法支撑目标规模。
- 静态服务端图片：无法支持用户自由探索和关系切换。
