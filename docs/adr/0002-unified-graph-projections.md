# ADR-0002：统一底层图谱与多视图投影

## Status

Accepted

## Context

产品需要完整空间图、目录图、代码结构图、方法图、调用图、数据关系图和数据链路图。如果每种图独立建模和存储，同一个代码实体会重复存在，关系难以跨视图连接，知识标注也难以复用。

## Decision

建立一份带类型、来源、证据类别和可信度的统一属性图。所有具体图都是针对节点类型、关系类型、根节点、深度和过滤条件生成的查询投影。保存视角保存可重放查询和布局信息，不复制事实图谱。

## Consequences

### Positive

- 不同视图共享实体身份、关系和人工知识。
- 可以从目录、方法、调用或数据关系无缝切换。
- 新数据源和新图类型可以增量加入。
- 图谱变化后保存视角可以重放并比较差异。

### Negative

- 统一 Schema 和稳定 ID 设计更复杂。
- 查询引擎必须处理异构节点、证据和预算。
- 投影结果需要明确说明聚合和截断状态。

### Neutral

- 视图拥有自己的布局，但不拥有独立事实副本。

## Alternatives Considered

- 每类图独立数据库：实现局部简单，但长期形成数据孤岛。
- 只保留 CodeGraph 原始模型：无法自然表达人工知识、数据 Schema 和运行时证据。
