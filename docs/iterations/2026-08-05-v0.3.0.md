# CodeAtlas v0.3.0 迭代记录

- 开始日期：2026-08-05
- 分支：`codex/v0.3-data-flow`
- 状态：设计完成，开发中
- 目标：让用户从 HTTP 接口或数据表切入，查看 Java/Spring/MyBatis 的静态数据访问链路。

## 第一阶段范围

```text
Route → Controller → Service → Mapper → SQL → Table
```

- 复用 CodeGraph 已识别的路由、方法调用、Mapper 接口和 MyBatis XML SQL 节点。
- CodeAtlas 增加数据表节点及 `READS_FROM`、`WRITES_TO`、`MAPS_TO` 关系。
- 支持 MyBatis XML 与 MyBatis-Plus `@TableName`、`BaseMapper<Entity>`。
- 新增“数据链路”投影，支持项目筛选、搜索、上下游探索和节点拖动。
- 所有推导保留证据来源、置信度与不完整原因。

## 验收标准

- [ ] 解析 XML SELECT/JOIN、INSERT、UPDATE 和 DELETE 表关系。
- [ ] 解析 MyBatis-Plus 实体与 Mapper 表映射。
- [ ] 多项目同名表节点不冲突。
- [ ] API 只返回能够到达数据表的数据链路。
- [ ] Web 提供数据链路视图并清楚表达读写方向。
- [ ] 真实五项目空间至少验证一条接口到表的完整链路。
- [ ] 完整测试、类型检查、构建、E2E、视觉验收和 GitHub CI 通过。

## 架构决定

- 使用 CodeGraph + CodeAtlas 数据访问增强层，不重复构建 Java 调用图。
- v0.3.0 第一阶段回答“谁读写了哪些表”，字段级值传播留到后续版本。
- 动态 SQL 无法确定表名时不生成确定事实，必要时标记为启发式证据。
- `main` 继续保持保护状态，开发和文档通过功能分支与 PR 交付。

## 已知限制

- 第一阶段仅支持 Java/Spring/MyBatis，不解析其他 ORM。
- 不连接真实数据库，不验证运行时实际执行路径。
- 不实现字段级污点传播、事务边界或动态数据源解析。
