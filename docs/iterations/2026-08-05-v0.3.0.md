# CodeAtlas v0.3.0 迭代记录

- 开始日期：2026-08-05
- 分支：`codex/v0.3-data-flow`
- 状态：设计完成，开发中
- 目标：建立多语言数据链路能力，并首先让用户从 HTTP 接口或数据表切入，查看 Java/Spring/MyBatis 的静态数据访问链路。

## 第一阶段范围

```text
Route → Controller → Service → Mapper → SQL → Table
```

- 复用 CodeGraph 已识别的路由、方法调用、Mapper 接口和 MyBatis XML SQL 节点。
- CodeAtlas 增加数据表节点及 `READS_FROM`、`WRITES_TO`、`MAPS_TO` 关系。
- 支持 MyBatis XML 与 MyBatis-Plus `@TableName`、`BaseMapper<Entity>`。
- 新增“数据链路”投影，支持项目筛选、搜索、上下游探索和节点拖动。
- 所有推导保留证据来源、置信度与不完整原因。

Java/Spring/MyBatis 是 v0.3.0 的首个 Provider 和真实验收样本，不是数据链路核心支持范围的上限。后续语言和框架通过同一 Provider 契约接入；同一个多语言项目允许多个 Provider 同时贡献图谱事实。

## 验收标准

- [x] 解析 XML SELECT/JOIN、INSERT、UPDATE 和 DELETE 表关系。
- [x] 解析 MyBatis-Plus 实体与 Mapper 表映射。
- [x] SQL 提取器不依赖 Java 或特定 ORM。
- [x] Provider 注册器支持多 Provider、能力探测、去重和故障隔离。
- [x] 多项目同名表节点不冲突。
- [ ] API 只返回能够到达数据表的数据链路。
- [ ] Web 提供数据链路视图并清楚表达读写方向。
- [ ] 真实五项目空间至少验证一条接口到表的完整链路。
- [ ] 完整测试、类型检查、构建、E2E、视觉验收和 GitHub CI 通过。

## 架构决定

- 使用 CodeGraph + CodeAtlas 数据访问增强层，不重复构建 Java 调用图。
- 数据链路核心保持语言无关，框架知识封装在内部 Provider 中。
- v0.3.0 先稳定内部 Provider 契约；第二种真实语言接入后再评估公开插件 SDK。
- Provider 根据项目特征独立探测；多语言项目不使用排他的单语言开关。
- v0.3.0 第一阶段回答“谁读写了哪些表”，字段级值传播留到后续版本。
- 动态 SQL 无法确定表名时不生成确定事实，必要时标记为启发式证据。
- CodeGraph 的 Route→method `REFERENCES` 在满足明确节点类型条件时归一化为 `ROUTES_TO`，其他引用关系不变。
- `main` 继续保持保护状态，开发和文档通过功能分支与 PR 交付。

## 真实项目检查

对 `jxt_scf_ksydtcorescf` 执行 Provider 级只读验证：

- 自动探测结果：`supported = true`
- 生成 459 个 Overlay 节点、477 条边。
- 其中包含 138 个表、210 个 XML SQL 节点、111 条 `MAPS_TO`、365 条 `READS_FROM` 和 1 条 `WRITES_TO`。
- 3 个超过 2 MB 安全上限的 Java 文件被跳过并生成 warning；其他文件继续完成提取。

五项目完整快照合并验证：

- 总计 70,904 个节点、188,532 条边，其中 167 个表节点、534 条数据关系。
- 保留 3 条 Provider warning，未影响任何兼容 CodeGraph 项目的可用状态。
- 已验证 8 段真实静态链路：`LearnFacadeServiceImpl.getDailyPlan → ILearnService → LearnServiceImpl → queryCompletedTaskIds → LearnDao → LearnDaoImpl → LearnTaskCompletionMapper → XML selectCompletedTaskIds → t_learn_task_completion`。
- SQL 与 Mapper Provider 锚点成功复用 CodeGraph 原节点，没有重复生成符号节点。
- 当前五项目中 HTTP Route 位于 API 项目，表访问位于独立 core 项目；独立 CodeGraph 数据库之间尚无方法级跨项目边，因此“Route 到 Table”完整验收仍保持未完成。

## 已知限制

- v0.3.0 首个发行 Provider 仅覆盖 Java/Spring/MyBatis；其他语言尚未提供实现，但核心不受 Java 限制。
- 当前不展开 MyBatis `<include>` 引用的 SQL 片段，也不解析注解内联 SQL；相应表关系可能暂时缺失。
- 独立项目索引之间暂未建立 Java 方法级跨项目调用关系，API Route 无法自动跨项目连接到 core 服务的数据表。
- 不连接真实数据库，不验证运行时实际执行路径。
- 不实现字段级污点传播、事务边界或动态数据源解析。
