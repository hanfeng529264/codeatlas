# CodeAtlas 节点拖动设计

## 目标

用户可以把图谱中的单个节点拖到新的位置，以便拆开重叠节点、观察关系方向和阅读连线。节点松开后固定在当前位置；切换视图、切换项目、进入局部图或刷新页面时恢复该图谱的默认布局。

## 交互约定

- 在节点上按下鼠标并移动超过 4 像素后开始拖动。
- 拖动期间暂停画布平移，节点坐标与相连边实时更新。
- 松开鼠标后结束拖动，节点保留当前坐标。
- 未超过阈值的按下与松开仍视为普通点击，继续打开节点详情。
- 完成实际拖动后吞掉紧随其后的点击事件，避免误选或清空当前节点。
- 鼠标松开、离开或组件卸载时必须清理拖动状态并恢复画布光标。
- 拖动位置只存在于当前浏览器图实例，不写入 CodeGraph、CodeAtlas 配置或其他数据库。

## 实现结构

新增纯状态控制器，负责拖动开始、移动阈值、结束和点击抑制，可脱离浏览器进行单元测试。`GraphCanvas` 监听 Sigma 的 `downNode` 和 MouseCaptor 的 `mousemovebody`、`mouseup` 事件；移动时通过 `viewportToGraph` 将鼠标坐标转换为图坐标，然后更新 Graphology 节点的 `x`、`y` 属性并刷新 Sigma。开始拖动时冻结当前边界框，避免单节点移动触发整张图自动缩放。

图谱数据、视图或项目发生变化时，React 会销毁旧 Sigma 实例并从投影数据重建图，因此拖动位置自然恢复。事件监听器在 effect 清理阶段显式解绑，防止重复监听和内存泄漏。

## 验证

- 单元测试覆盖：轻点不触发拖动、超过阈值触发拖动、拖动后只抑制一次点击、结束后可开始下一次拖动。
- 完整运行 Vitest、Node/Web 类型检查、生产构建和 Playwright 测试。
- 在真实多项目图谱中拖动一个节点，确认节点固定、连线跟随、画布不平移；刷新后确认默认布局恢复。
