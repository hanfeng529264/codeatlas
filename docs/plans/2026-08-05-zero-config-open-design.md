# 零配置打开设计

- 日期：2026-08-05
- 版本：v0.2.0
- 分支：`codex/v0.2-multi-project`
- 目标：普通用户只需执行 `codeatlas open .`，无需理解工作空间、项目注册、索引或端口。

## 默认流程

`open` 负责完成整条准备链路：

1. 当前路径没有工作空间时自动初始化。
2. 存在 `projects/` 时自动扫描其一级子项目。
3. 将旧的单一根项目注册安全转换为多项目注册，不删除代码或索引。
4. 自动注册新发现的项目。
5. 为缺少 CodeGraph 索引的项目自动建索引。
6. 默认端口被占用时由操作系统自动选择可用端口。
7. 启动 Web 应用并打开浏览器。

`init` 同样默认启用项目发现，因此重复执行可以修复已经初始化但尚未注册子项目的工作空间。

## 控制与安全

自动发现只使用 `project scan` 已验证的一级目录规则。高级用户可以使用 `--no-discover` 禁止发现，使用 `init --empty` 明确创建空工作空间。`status` 保持只读，不在状态检查过程中修改配置或建立索引。

自动转换只发生在工作空间恰好注册了一个路径为 `.` 的根项目，并且约定的 `projects/` 下发现真实项目时。转换仅修改 `.codeatlas/workspace.json`；原根目录 `.codegraph` 不会被删除。

## 验证

- CLI 测试覆盖初始化时自动发现、关闭发现以及未初始化路径的 open 准备流程。
- 既有单项目初始化保持根项目行为。
- 完整单元、集成、构建和浏览器端到端测试继续通过。
