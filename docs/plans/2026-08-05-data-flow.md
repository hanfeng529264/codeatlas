# Data Flow Graph Implementation Plan

**Goal:** Build a language-neutral data-flow foundation and ship Java/Spring/MyBatis as its first framework Provider.

**Architecture:** Providers detect applicable project artifacts and emit a common graph overlay. A registry combines all matching Providers for polyglot projects, deduplicates facts, and isolates failures. CodeGraph supplies the existing code-call evidence; CodeAtlas adds table nodes and `READS_FROM`, `WRITES_TO`, and `MAPS_TO` edges.

**Tech Stack:** TypeScript, Node.js filesystem APIs, CodeGraph SQLite, Fastify, React, Graphology, Sigma.js, Vitest, Playwright.
