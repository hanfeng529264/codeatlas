# Data Flow Graph Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a Java/Spring/MyBatis data-flow projection that connects existing CodeGraph call evidence to SQL tables.

**Architecture:** Reuse CodeGraph nodes and call edges, then merge a source-derived overlay containing table nodes and `READS_FROM`, `WRITES_TO`, and `MAPS_TO` edges. GraphStore exposes a table-reachable projection and the React UI renders it as a sixth graph view.

**Tech Stack:** TypeScript, Node.js filesystem APIs, CodeGraph SQLite, Fastify, React, Graphology, Sigma.js, Vitest, Playwright.
